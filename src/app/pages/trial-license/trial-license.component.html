Trial license

A trial license is time-boxed evaluation access. Duration is set at issuance; when time runs out the license becomes Expired and the customer must purchase, extend, or enter a paid key.

Fixed window

Days + optional hours from issue or activation.

Trials dashboard

Active, Expired, Converted, Cancelled.

Conversion funnel

Extend, end, or upgrade to paid type.

Trial license — for product owners

Offer time-boxed evaluation access. LicenPro supports trials through the license wizard (type Trial) and the dedicated Trials area (/dashboard/trials) for extension requests and conversion tracking.

Issue a trial

  • License wizard — Generate License → Trial → set trial period (days/hours).
  • Trials API — POST /api/trials for release-scoped trial records and extension workflow.
  • Attach an entitlement set to limit features during evaluation.

Operate & convert

  • Trials dashboard — filter Active, Expired, Converted, Cancelled.
  • Extend — add days during sales negotiations (POST /api/trials/{id}/extend).
  • Review extension requests — prospects can request more time; approve or reject in Trials UI.
  • Convert — issue a paid Perpetual or Subscription; mark trial converted.
  • End early — stop abuse before natural expiry.

Free LicenPro accounts can issue Perpetual and Trial license types; other types typically require a paid platform plan.

See Trials platform guide and Trials API.

Trial license — for end users

A trial gives full or limited product access until the end date. When it expires, the app stops validating until you purchase or receive an extended trial.

Getting started

  1. Sign up or receive a trial key from the vendor.
  2. Install the app and activate with the trial license file.
  3. Use the product within the trial window — watch in-app expiry warnings.

When the trial ends

  • Validation returns expired — purchase a paid license to continue.
  • Some vendors accept an extension request before expiry (contact sales or in-app form).

Troubleshooting

SituationWhat to do
Trial expired yesterdayBuy a subscription/perpetual key or ask sales for extension
Extension approved but still expiredRestart app or wait for next online validation
Features missing vs marketing pageTrial entitlement set may be limited — check with vendor

Compare with other models

  • vs Subscription — trial is short evaluation; subscription is paid recurring term.
  • vs Perpetual — trial always expires; perpetual does not by default.
